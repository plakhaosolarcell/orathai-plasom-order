# 🐟 อรทัยปลาส้ม ออเดอร์ (Orathai Plasom Order)

## ยินดีต้อนรับเข้าสู่แอปพลิเคชันสั่งซื้อปลาส้ม Premium 🎉

แอปพลิเคชันออนไลน์สำหรับสั่งซื้อปลาส้มโนนกาหลง สิรินธร ของเรา พร้อมบริการส่งถึงบ้านคุณ

### ✨ คุณสมบัติหลัก

- 🛒 **เลือกสินค้า** - ปลาส้มปลาตะเพียน, ปลาส้มปลาจีน, ปลาส้มน้อย
- 📦 **ระบบสั่งซื้อ** - เพิ่ม/ลดปริมาณง่ายดาย
- 🚚 **คำนวณค่าจัดส่ง** - อัตโนมัติตามน้ำหนัก (35 บาท/kg)
- 💳 **ชำระเงิน** - ผ่าน PromptPay QR Code
- 📍 **กรอกที่อยู่** - ส่งถึงบ้านทั่วประเทศ
- 📋 **ดาวน์โหลด PDF** - ใบสั่งซื้อสำหรับบันทึก

### 🎨 ดีไซน์ Premium

- ออกแบบสมัยใหม่ด้วยสีสันสวยงาม
- เหมาะสำหรับมือถือและคอมพิวเตอร์
- ประสบการณ์ผู้ใช้ที่ราบรื่น

### 📱 วิธีใช้งาน

1. เปิดแอปพลิเคชัน
2. เลือกสินค้าและปริมาณที่ต้องการ
3. กรอกข้อมูลการจัดส่ง
4. ชำระเงินผ่าน PromptPay
5. ดาวน์โหลด PDF ใบสั่งซื้อ
6. รอการส่ง 📦
