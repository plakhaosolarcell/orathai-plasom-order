✅ ปรับปรุงที่ทำไปแล้ว

  • ✨ เพิ่มขอบข้าง (Border): กรอบสีดำ 3px รอบเนื้อหาทั้งหมด เพื่อให้ดูเป็นเอกสารอย่างเป็นทางการ
  • ระยะขอบ (Margins): ปรับเพื่อให้มีช่องว่างที่สมดุลด้านบน-ล่าง (15mm) และซ้าย-ขวา (20mm)
  • ขนาดตัวอักษร: ปรับให้อ่านชัดเจนขึ้น - หัวข้อหลัก 20px, ชื่อส่วน 11px, ข้อความ 10px
  • ระยะห่างส่วน: เพิ่มระยะห่างระหว่างส่วนต่างๆ ให้เหมาะสม
  • การจัดวาง: ปรับให้มีเนื้อที่ว่างเหลือด้านข้างเท่าๆ กัน
  • ตารางสินค้า: เพิ่มช่องว่างในเซลล์เพื่อให้อ่านง่ายขึ้น
  • ยอดรวม: เน้นให้ชัดเจนด้วยกรอบและสีแดง

📝 รายละเอียดการปรับปรุง

  • ระยะขอบบน/ล่าง: 8mm → 15mm (ให้เนื้อที่ว่างมากขึ้น)
  • ระยะขอบซ้าย/ขวา: 25mm → 20mm (สมดุลกว่า)
  • หัวข้อหลัก: 18px → 20px
  • ชื่อส่วน: 10px → 11px
  • ระยะห่างระหว่างส่วน: 4-5mm → 5-6mm
  • ความสูงของแถวสารสนเทศ: 1.5mm → 2mm padding
  • เนื้อที่ในตาราง: เพิ่ม padding 2mm → 2.5-3mm
